# 08 · 算子库构成与原理

> 返回索引：[README.md](README.md)

verl 的"算子库"分三层：**融合 kernel** / **模型桥接(mcore)** / **HF monkey patch**。

## 8.1 融合 Kernel（`verl/utils/kernel/`）

```
 LinearCrossEntropy (Triton, autograd.Function)
   输入: hidden(B*T,H), weight(V,H), labels, temperature, dist_process_group
   融合: lm_head 投影 + log_softmax + gather(label) + token entropy
   价值: 不物化 (B*T, V) logits 张量 -> 显存 O(T·V) 降到 ~O(T)
        大词表(如 150K) RL 训练防 OOM；支持 TP 词表切分跨 rank 规约
```

还包括 fp8 相关 kernel（`models/mcore/fp8_kernel.py`）等。这类算子直击 RL 训练"logits 显存爆炸"痛点，是吞吐与可训练规模的关键。

## 8.2 模型桥接层（`verl/models/mcore/`）

HF ↔ Megatron-Core 的双向转换中枢（四张注册表，registry.py）：

```
 hf_to_mcore_config()   : HF config -> Megatron TransformerConfig
                          (num_kv_heads->num_query_groups, RMSNorm, SwiGLU...)
 init_mcore_model()     : 实例化 mcore GPTModel (Dense/MoE/DeepSeekV3/VL...)
 MODEL_FORWARD_REGISTRY : 支持 sequence packing 的 forward
 get_mcore_weight_converter() : mcore(融合QKV/gate-up) <-> HF 命名/切分
                          -> 在线把训练权重转回 HF 给 vLLM/SGLang rollout
```

支持架构涵盖 LLAMA / QWEN2,3 / QWEN-MoE / DEEPSEEK_V3 / MIXTRAL / QWEN2.5-VL / GLM4-MoE / GPT-OSS 等。集成方式演进：逐模型实现(旧, 已弃用) → mbridge → megatron-bridge(推荐)。MTP（Multi-Token Prediction）由 `mtp_patch.py` 支持。

> 已核验（当前代码）：`verl/models/` 顶层只剩 `mcore/` 与 `transformers/` 两个子目录，旧式逐模型 Megatron 目录已移除（`models/registry.py` 仍保留动态 import 路径 `verl.models.{name}.megatron.modeling_*_megatron` 作为兼容/预留，不再有对应目录）。`models/mcore/` 现包含：`bridge.py`、`mbridge.py`、`patch.py`（megatron-bridge 三件套）、`config_converter.py`、`loader.py` / `saver.py` / `weight_converter.py`、`model_initializer.py`、`model_forward.py` / `model_forward_fused.py` / `model_forward_1f1b_overlap.py`（sequence packing + 1F1B overlap 前向）、`mtp_patch.py`、`registry.py`、`util.py`。

## 8.3 HF Monkey Patch（`verl/models/transformers/`）

在不改 transformers 源码的前提下，向 HF 模型注入：
- **Ulysses 序列并行** patch（跨 seq 维切 attention）。
- **Flash-Attention / 变长 attention** patch。
- **position_ids / 多模态** 处理 patch。
- Liger-kernel 集成（`USE_LIGER=1`，融合 RMSNorm/SwiGLU/CE 等）。

当前目录文件：`llama.py` / `qwen2.py` / `qwen3_5.py` / `qwen2_vl.py` / `qwen3_vl.py` / `glm4v.py` / `kimi_vl.py` / `apertus.py` / `dense_common.py` / `tiled_mlp.py` / `monkey_patch.py` / `npu_patch.py`（新增大模型常见文件：`dense_common.py` 为 dense 模型公共 patch、`tiled_mlp.py` 为 tiled MLP 支持）。

## 8.4 数学/张量工具（`verl/utils/torch_functional.py` 等）

`logprobs_from_logits` / `masked_mean` / `masked_whiten` / `allgather_dict_tensors` 等，是算法层（GAE 归一、loss 聚合）与通信层（跨 rank 聚合 DataProto）的底层支撑。
